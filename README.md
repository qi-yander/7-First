# 生态系统模拟系统
C++面向对象课程设计，模拟狼‑羊草原食物链仿真。

## 📖项目介绍
本程序基于继承关系设计基类Organism生物类，派生出Wolf狼类、Sheep羊类。
- 狼：随机移动、消耗体力、对猎物执行hunt捕猎行为
- 羊：基础生物生存逻辑
主程序维护种群容器，循环仿真，统计存活个体数量，程序结束释放堆内存。

## 💻编译运行
开发工具：Visual Studio 2026
1.下载源代码，打开 `生态系统模拟系统终.sln` 解决方案
2.直接点击本地Windows调试器编译运行即可

## 📁文件结构
- Organism.h / Organism.cpp：生物基类
- Wolf.h / Wolf.cpp：狼子类，移动、捕猎hunt函数
- Sheep.h / Sheep.cpp：羊子类
- main.cpp：仿真主函数，种群调度、统计输出、内存释放
